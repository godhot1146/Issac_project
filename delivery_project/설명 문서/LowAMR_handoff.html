LowAMR 인수인계 문서

1. 목적 / 역할

LowAMR은 IsaacGym 시뮬레이션 안에서 저상형(low-profile) AMR 액터 하나를 제어하는 클래스다. 승강(prismatic) + 회전(turntable) 조인트로 선반을 들어올리며, 리프트가 상승한 상태에서는 차체가 회전해도 화물의 월드 방향이 고정되도록 리프트 조인트를 반대로 돌리는 카운터 회전(Yaw-Lock) 기능을 지원한다.

LowAmrMotionStep은 "어디로(X/Y), 어떤 순서(축 우선순위)로, 어느 방향을 보며, 리프트를 얼마나 올리고 몇 도 돌릴지"를 하나의 이동 스텝으로 선언하는 순수 데이터 클래스이며, LowAmrStepRunner는 이 스텝 리스트를 받아 8단계 서브스테이지로 순차 실행하는 상태머신이다(로직·데이터 분리 구조).

2.4 사용법 예시 (~/isaacgym/python/delivery_project/tests/test_lowamr.py 기준) 

gym, sim, env, args = create_minimal_sim("LowAMR Scenario Test")
viewer = create_viewer(gym, sim, env, cam_pos=(3.0, -3.0, 2.5), cam_target=(0.0, 0.0, 0.3))

low_asset = load_asset(
    gym, sim, "urdf/low/v2/low_amr_v2.urdf",
    fix_base_link=False, replace_cylinder_with_capsule=True,
)
low_handle = gym.create_actor(env, low_asset, gymapi.Transform(p=gymapi.Vec3(0.0, 0.0, 0.3)), "low_amr_test", -1, 1)
low_amr = LowAMR(gym, sim, env, low_handle)

gym.prepare_sim(sim)

steps = [
    LowAmrMotionStep(
        "MOVE_AND_LIFT",
        target_x=1.2, target_y=0.0, axis_order='x',
        initial_facing='+x', direction1='FORWARD',
        mid_facing='+x', direction2='FORWARD',
        final_facing='+x',
        lift_height=0.16, lift_rotate_angle=0.5,
        lift_yaw_lock=True,
        hold_seconds=1.0,
    ),
    LowAmrMotionStep(
        "RETURN_AND_LOWER",
        target_x=0.0, target_y=0.0, axis_order='x',
        initial_facing='+x', direction1='BACKWARD',
        mid_facing='+x', direction2='BACKWARD',
        final_facing='+x',
        lift_height=0.0, reset_lift_plate=True,
        lift_yaw_lock=False,
        hold_seconds=1.0,
    ),
]
runner = LowAmrStepRunner(low_amr, steps, context=StepContext(low_amr=low_amr))

# 메인 루프에서 매 프레임:
if not runner.done:
    runner.update(frame_count)

3. Public API 레퍼런스

3.1 LowAmrMotionStep

항목 역할 비고
__init__(name, target_x, target_y, axis_order='x', initial_facing=None, direction1='FORWARD', mid_facing=None, direction2='FORWARD', final_facing='+x', lift_height=None, lift_threshold=0.01, reset_lift_plate=False, lift_rotate_angle=None, lift_rotate_threshold=0.02, lift_yaw_lock=None, hold_seconds=0.1, wait_for=None, on_enter=None, on_complete=None) 하나의 이동 스텝을 선언. axis_order='x'면 X축을 먼저, 'y'면 Y축을 먼저 정렬·주행한다
target_x, target_y 스텝의 최종 목표 좌표
initial_facing / mid_facing 1구간/2구간 이동 전 정렬할 명시적 방향('+x'/'-x'/'+y'/'-y') LowAmrStepRunner._resolve_facing이 처리
direction1 / direction2 1구간/2구간 주행 시 전진(FORWARD)/후진(BACKWARD) 여부
final_facing XY 도달 후 최종적으로 맞출 방향
lift_height 이 스텝에서 도달해야 할 리프트 높이(m). None이면 리프트 단계를 건너뜀
lift_threshold 리프트 높이 도달 판정 허용오차(m) 기본 0.01
reset_lift_plate 스텝 진입 시 Yaw-Lock을 해제하고 회전판을 즉시 0rad로 리셋할지 여부
lift_rotate_angle 회전판 목표 각도(rad). None이면 회전 단계를 건너뜀(이전 각도 유지)
lift_rotate_threshold 회전판 각도 도달 판정 허용오차(rad) 기본 0.02rad(약 1.15°)
lift_yaw_lock True: hold 종료 시점의 각도를 기준으로 Yaw-Lock 활성화 / False: 해제 / None: 현재 상태 유지 hold 단계가 끝나는 시점에 반영됨
hold_seconds 회전까지 끝난 뒤 정지 유지할 시간(초)
wait_for(context) -> bool 스텝 진입 전 대기 조건. False를 반환하는 동안 계속 대기 스텝에 처음 진입하기 전에만 검사
on_enter / on_complete 스텝 진입/완료 시 실행할 콜백 리스트(callback(context))

3.2 LowAmrStepRunner

메서드 역할 언제 호출해야 하는가
__init__(low_amr, steps, context=None) 실행할 LowAmrMotionStep 리스트와 제어 대상 LowAMR 인스턴스를 주입 스텝 시퀀스를 시작하기 전 1회
update(frame_count=0) 현재 스텝의 현재 서브스테이지를 1프레임만큼 진행. 내부에서 _update_lift_yaw_lock()과 apply_actuator_commands()를 항상 마지막에 호출 매 프레임, self.done이 True가 될 때까지
done (속성) 모든 스텝을 완료했는지 여부 시퀀스 종료 판단용으로 매 프레임 확인

3.3 LowAmrStepRunner — 내부(private) 헬퍼 메서드

메서드 역할 호출하는 곳
_current_step() self.steps[self.index] 반환 update() 최초 진입부
_resolve_facing(explicit_facing, axis, target_coord, direction) 명시적 방향이 있으면 그대로 변환, 없으면 현재 위치·목표좌표·전후진 여부로부터 최단 방향의 yaw를 자동 계산 SUB_INITIAL_FACING, SUB_MID_FACING
_advance_to_next_step(step) on_complete 콜백 실행 → index 증가 → 서브스테이지/진입 플래그 초기화 → 마지막 스텝이면 done=True SUB_HOLD 종료 시, _enter_hold에서 hold_seconds==0일 때
_apply_lift_yaw_lock_request(step) step.lift_yaw_lock 값(True/False/None)에 따라 start_lift_yaw_lock/stop_lift_yaw_lock을 실제로 호출 SUB_HOLD 종료 시점, _enter_hold에서 hold_seconds==0일 때
_enter_hold(step, frame_count) hold_seconds > 0이면 SUB_HOLD로 전환하고 시작 프레임 기록, 0이면 즉시 yaw-lock 반영 후 다음 스텝으로 SUB_LIFT_ROTATE 완료 시

3.4 모듈 함수

함수 역할 비고
LowAMR_direction_to_yaw(direction_str) '+x'/'-x'/'+y'/'-y' 문자열을 라디안 yaw 값으로 변환 허용되지 않는 문자열이면 ValueError. ForkliftAMR.direction_to_yaw와 동일 로직을 LowAMR 전용으로 재정의

3.5 LowAMR — 초기화 / 튜닝

메서드 역할 언제 호출해야 하는가
__init__(gym, sim, env, handle) 하드웨어 상수·상태 변수 초기화 후 _cache_joint_indices() → configure_actuators() → configure_contact_surface() → _configure_lift()를 순서대로 실행 액터 생성 직후 1회
configure_actuators(damping=800.0, max_effort=100000.0) 전체 DOF를 우선 속도(VEL) 제어 모드로 초기화하고, 구동륜(좌/우 바퀴)의 effort/velocity만 강화. 리프트 승강/회전 조인트의 POS 모드 및 게인은 관여하지 않음(_configure_lift()가 전담) __init__ 내부에서 1회
configure_contact_surface(caster_friction=0.0, drive_friction=2.5) 캐스터/구동륜/리프트 링크별로 마찰·반발계수를 분리 세팅 __init__ 내부에서 1회
apply_actuator_commands() 공유 버퍼(dof_position_targets, dof_velocity_targets)를 물리 엔진에 실제로 주입 매 프레임, 다른 제어 메서드 호출 이후 마지막에 (StepRunner가 자동 호출)
seconds_to_frames(seconds) LIFT_FRAME_DT(1/60초) 기준으로 초→프레임 수 환산 hold 시간 등을 프레임 단위로 바꿔야 할 때

3.6 LowAMR — 리프트 승강/회전

메서드 역할 언제 호출해야 하는가
set_lift_height(target_height) 목표 높이(0.0~0.2m로 클램프)를 슬루 레이트(MAX_LIFT_STEP/프레임)로 서서히 따라가도록 dof_position_targets에 주입 리프트를 올리고 싶을 때 매 프레임 지속 호출(목표값이 그대로여도 램프 진행을 위해 계속 호출 필요)
get_lift_height() 리프트 조인트의 실제 물리 위치(m) 조회 목표 도달 여부 판정 등
set_lift_rotation(target_rad) 회전판 목표 각도(rad, 범위 클램프)를 즉시 dof_position_targets에 주입(슬루 레이트 없음) rotate_lift_to_angle/_update_lift_yaw_lock/reset_lift_plate 처리에서 내부적으로 사용
get_lift_rotation() 회전판 조인트의 실제 각도(rad) 조회
rotate_lift_to_angle(target_rad, threshold=0.01) 회전판을 목표각으로 회전, 최단 각도 오차가 threshold 이내면 True 회전판을 직접 특정 각도로 돌리고 싶을 때 매 프레임 지속 호출

3.7 LowAMR — Yaw-Lock

메서드 역할 언제 호출해야 하는가
start_lift_yaw_lock(target_local_angle=None) 카운터 회전 잠금을 시작. 호출 시점의 차체 yaw를 기준(0)으로 잡고, target_local_angle(생략 시 현재 회전판 각도)을 잠금 기준 각도로 저장 화물을 완전히 들어올려 안정화된 직후
stop_lift_yaw_lock() 잠금 해제(마지막 각도는 유지됨) 회전판을 직접 조작해야 할 때, 또는 화물을 내려놓기 전

3.8 LowAMR — Yaw-Lock 내부(private) 헬퍼

메서드 역할 호출하는 곳
_update_lift_yaw_lock() 매 프레임 차체 yaw 변화량을 누적 추적해 회전판에 -delta를 반영. 리드(lead) 보정량을 별도로 슬루 레이트 적용해 오버슈트를 억제 LowAmrStepRunner.update()가 매 프레임 자동 호출

3.9 LowAMR — 주행

메서드 역할 언제 호출해야 하는가
get_pose() 로봇의 전역 위치(p)와 회전 쿼터니언(r) 반환 위치/방향이 필요한 곳에서
set_twist_velocity(linear_x, angular_z) ROS Twist 스타일 명령을 가속도 제한(슬루 레이트) 후 좌우 바퀴 각속도로 변환하여 dof_velocity_targets에 주입 직접 속도 명령이 필요할 때. turn_to_yaw/drive_along_axis가 내부적으로도 호출
turn_to_yaw(target_yaw) 목표 yaw까지 제자리 회전(P제어 + 회전 방향 잠금). 도달 시 True 방향 정렬이 필요한 모든 서브스테이지에서 매 프레임 지속 호출
drive_along_axis(axis, target_coordinate, direction="FORWARD") 지정 축(X/Y)을 따라 목표좌표까지 직진, 목표 yaw 유지 보정 포함. 도달 시 True 직선 구간 이동이 필요할 때 매 프레임 지속 호출

3.10 LowAMR — 내부(private) 헬퍼 메서드 (초기화/기타)

메서드 역할 호출하는 곳
_cache_joint_indices() 구동륜/리프트/회전판 조인트 인덱스를 1회 조회해 캐싱, 없으면 경고 로그 출력 __init__ 내부에서 1회
_configure_lift() 리프트 승강/회전 조인트를 POS 모드로 전환하고 강성/감쇠/속도/토크를 세팅 __init__ 내부에서 configure_actuators() 이후 반드시 마지막에 1회
_get_current_yaw(q) 쿼터니언에서 yaw(rad) 추출 turn_to_yaw, drive_along_axis, start_lift_yaw_lock, _update_lift_yaw_lock, LowAmrStepRunner.update 등 거의 모든 방향 계산의 기반

4. 튜닝 파라미터

파라미터 값 용도 / 근거
TRACK_WIDTH 0.60 m 좌우 구동륜 간 거리. 차동 구동 기구학(set_twist_velocity)의 회전 반경 계산에 사용
WHEEL_RADIUS 0.15 m 선속도 ↔ 바퀴 각속도(rad/s) 환산
MAX_LINEAR_VEL / MAX_ANGULAR_VEL 1.0 m/s / 2.0 rad/s 무부하(리프트 미상승) 상태의 최대 속도 한계 (오버슈트 리스크와 트레이드오프가 있다)
MIN_LINEAR_VEL / MIN_ANGULAR_VEL 0.25 m/s / 0.5 rad/s 무부하 상태에서 P제어 속도가 너무 느려 멈추지 않도록 하는 하한 (오버슈트 리스크와 트레이드오프가 있다)
LIFT_MIN_LINEAR_VEL / LIFT_MIN_ANGULAR_VEL 0.25 m/s / 0.5 rad/s 화물을 든 상태(get_lift_height() > 0.1)에서 적용되는 최소 속도. 현재 수치는 무부하 하한과 동일 — 화물 하중을 고려해 별도로 낮출지 검토 여지 있음

Kp_STRAIGHT_ANG(drive_along_axis 로컬 상수) 4.5 직진 중 목표 yaw 유지를 위한 조향 보정 게인

DISTANCE_THRESHOLD(drive_along_axis 로컬 상수) 0.01 m 축 이동 도달 판정 허용오차

리프트 승강 조인트 (_configure_lift, 유일한 설정 지점) driveMode=POS, stiffness=500000, damping=20000, velocity=LIFT_RAMP_RATE_MPS, effort=500000 set_lift_height()가 이미 슬루 레이트로 목표를 서서히 이동시키므로, 강성은 그 램프된 목표를 오차 없이 따라가는 수준으로 매우 높게 설정. velocity를 슬루 레이트와 동일하게 맞춰 물리 엔진 자체의 속도 제한과 이중으로 충돌하지 않도록 함
리프트 회전 조인트 (_configure_lift, 유일한 설정 지점) driveMode=POS, stiffness=8000, damping=400, effort=30000, velocity=10.0 승강 조인트만큼 극단적인 강성은 필요 없어 URDF 한계치 내에서 안정적으로 세팅.
LEAD_TIME(_update_lift_yaw_lock 로컬 상수) 0.05 s Yaw-Lock 리드 보정에서, 현재 각속도로 얼마나 앞서 예측해 반영할지. 크면 오버슈트/진동 발생
LEAD_RAMP_RATE_DPS / MAX_LEAD_STEP 120 deg/s → 프레임당 라디안 환산 리드 보정량 자체의 슬루 레이트. 즉시 반영하지 않고 서서히 따라가게 함
LowAmrMotionStep.lift_threshold (기본) 0.01 m 스텝 단위 리프트 높이 도달 허용오차
LowAmrMotionStep.lift_rotate_threshold (기본) 0.02 rad(≈1.15°) 스텝 단위 회전판 각도 도달 허용오차
LowAmrMotionStep.hold_seconds (기본) 0.1 s 스텝 종료 전 정지 유지 시간(안정화 대기)

5. 참고사항

  • 차체가 회전해도 화물의 월드 방향이 고정되도록 리프트 조인트를 반대로 돌리는 회전 구현에서 차제 회전과 되도록 동시에 회전하도록 _update_lift_yaw_lock 함수 내부의 LEAD_TIME 값을 조절하였다. 하지만 완벽하게 자체의 회전을 상쇄하지 않고 시간차로 움직이며, 회전 시작과 끝에 떨림이 존재한다.
  • 화물의 무게가 많을 경우 lift_height가 목표값까지 도달하지 못할 수 있다. 이때 lift_threshold를 넉넉히 주거나, 리프트의 effort를 더 크게 설정하는 것을 고려할 수 있다.
